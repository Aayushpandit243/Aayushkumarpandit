# Aayush Kumar Panit — personal website

A simple, responsive personal website built with plain HTML, CSS, and JavaScript. It has no paid tools or dependencies.

## Put it online for free

GitHub Pages can host this site for free on a public repository. The free address will be based on your GitHub username, for example `yourusername.github.io`. The requested custom domain `Aayushkumapandit.com.np` is listed in `CNAME`. Nepal's official .np registry says registrations are free, subject to approval and name/document requirements.

1. Create a public GitHub repository named exactly `yourusername.github.io` (replace this with your GitHub username).
2. Upload `index.html` from this folder to the repository's top level.
3. In the repository, open **Settings → Pages** and choose **Deploy from a branch**, then select **main** and **/(root)** and save.
4. Wait for GitHub Pages to publish the site. It will be available at `https://yourusername.github.io`.
5. After the .np registry approves the domain, add the DNS records requested by GitHub Pages in the registry's domain management area. See GitHub's custom-domain guide for current DNS instructions.

The site's files are ready, but it is not public on the internet until you publish them from a GitHub account and the .np registry approves the domain. Personal .np applications must match the applicant name on accepted identity documents. Submit your application and identity documents from your own registry account.

## Personalize it

- In `index.html`, replace `hello@example.com` with your email address.
- Update the about text and interests to match you.
- The portrait is a CSS illustration, so there is no photo to upload or maintain.
